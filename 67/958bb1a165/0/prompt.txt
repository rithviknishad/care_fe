## The finding

Rule: `react-doctor/no-eval` (severity: error, category: Security, priority P0)
File: `src/hooks/useKeyboardShortcuts.ts`, line 65
Message: "`new Function()` is a code-injection vulnerability: it builds and runs code from a string."

The current code is:

```ts
const evaluateWhenCondition = useCallback(
  (whenClause: string): boolean => {
    if (whenClause === "always") return true;

    const evalContext = {
      canEdit: conditions.canEdit || false,
      canCreate: conditions.canCreate || false,
      readOnly: conditions.readOnly || false,
      questionnairesEnabled: conditions.questionnairesEnabled || false,
      ...conditions,
    };

    try {
      let expression = whenClause;
      Object.entries(evalContext).forEach(([key, value]) => {
        const regex = new RegExp(`\\b${key}\\b`, "g");
        expression = expression.replace(regex, String(value));
      });
      return new Function(`return ${expression}`)();
    } catch (error) {
      console.warn(`Failed to evaluate shortcut condition: ${whenClause}`, error);
      return false;
    }
  },
  [conditions],
);
```

## Step 3 — the fix

Replace the string evaluator with a safe evaluator. Write a small parser or evaluator that supports only what the `when` grammar needs:

- The literal `always`.
- Identifiers that name a key in `ShortcutConditions`.
- The operators `!`, `&&`, `||`.
- Parentheses.
- The literals `true` and `false`.

Any token that is not in this list must make the evaluator return `false` and log a warning, the same as the current `catch` block does.

Put the evaluator in its own module, for example `src/hooks/utils/evaluateShortcutCondition.ts`, and export a pure function. Follow `.github/instructions/hooks.instructions.md` and `.github/instructions/utils.instructions.md`.

Also fix the second defect in the same code: the current version does a text replace of every condition key into the expression string. A condition value that is a string could inject more code. Your evaluator must read values from the conditions object directly. It must never build a string.

Keep the exported behaviour of `useKeyboardShortcuts` the same. `when: "always"` must still return `true`.

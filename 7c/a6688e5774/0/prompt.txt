## Step 2 — there are two different root causes here

### Root cause A: an uncancelled `setTimeout` inside an effect

This is a real leak. Example, `src/components/ui/multi-filter/tagFilter.tsx`:

```tsx
useEffect(() => {
  if (!open) {
    setTimeout(() => { onSubMenuOpen(false); }, 100);
  } else {
    onSubMenuOpen(true);
  }
}, [open, onSubMenuOpen]);
```

The timer keeps running after the component unmounts. It then calls a parent callback on a component that is gone. Fix per recipe (A): capture the id and clear it.

```tsx
useEffect(() => {
  if (open) { onSubMenuOpen(true); return; }
  const id = setTimeout(() => { onSubMenuOpen(false); }, 100);
  return () => clearTimeout(id);
}, [open, onSubMenuOpen]);
```

`src/pages/Facility/settings/locations/LocationMap.tsx` has the same shape. It calls `setTimeout(() => fitView({...}), ...)` inside an effect. Read the whole effect. Apply the same fix.

### Root cause B: `form.watch(...)` called inside an effect or a helper function

The detector matches `.watch` as a subscription. In react-hook-form, `form.watch("name")` with a string argument reads a value; it does not return an unsubscribe handle. So there is no handle to release. But this is still a real defect, and the correct root-cause fix removes the `.watch` call from the effect.

The react-hook-form documentation says: do not call `watch()` inside an effect or a render-phase helper. Use the `useWatch` hook at the top level of the component. `useWatch` subscribes correctly, re-renders the component when the value changes, and cleans itself up on unmount. `form.watch()` inside an effect reads a value that the effect's dependency array does not track, so the effect can run with a stale value.

So for each of these sites, hoist the reads to `useWatch` at the top level of the component and add the resulting values to the effect dependency array:

```tsx
// before
useEffect(() => {
  const name = form.watch("name");
  const beds = form.watch("numberOfBeds");
  ...
}, [/* name and beds are not tracked */]);

// after
const name = useWatch({ control: form.control, name: "name" });
const beds = useWatch({ control: form.control, name: "numberOfBeds" });
useEffect(() => {
  ...
}, [name, beds]);
```
